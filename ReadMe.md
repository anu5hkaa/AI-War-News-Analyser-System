# AI War News Analyzer

An AI-powered news analysis system that retrieves and summarizes war and conflict-related news based on the user’s query.

Users can enter any country, conflict, or war-related topic, and the system fetches the most relevant news articles using semantic AI search and generates concise summaries.

Example queries:
- india china conflict
- iran us war
- russia ukraine war
- pakistan military tensions

## Features

- Semantic news search using SBERT
- FAISS vector similarity retrieval
- CrossEncoder reranking
- AI-generated summaries
- Live RSS news fetching
- Interactive query-based interface

##  Technologies Used

- Python
- SBERT
- FAISS
- CrossEncoder
- Groq API
- Pandas
- NumPy
- Google Colab
